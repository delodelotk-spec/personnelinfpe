🔗 Configuration Supabase officielle

L'URL et la clé INFPE sont pré-affichées. Cliquez sur 🔐⚡ Transférer + Enregistrer (mot de passe requis) pour forcer la configuration officielle, puis 🔄 Synchroniser maintenant.

📘 Script SQL — à exécuter UNE SEULE FOIS dans Supabase (SQL Editor)

CREATE TABLE IF NOT EXISTS infpe_data (
  site TEXT PRIMARY KEY,
  data JSONB NOT NULL,
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
ALTER TABLE infpe_data ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow all operations" ON infpe_data FOR ALL USING (true) WITH CHECK (true);
INSERT INTO infpe_data (site, data) 
VALUES ('INFPE', '{"agents":[],"mouvements":[],"messages":[],"settings":{},"columns":[]}')
ON CONFLICT (site) DO NOTHING;

Une fois ce script exécuté, toutes les modifications faites sur n'importe quel ordinateur sont automatiquement propagées aux autres postes via le Cloud.

Guide d'utilisation
Document détaillé pour faciliter la compréhension des utilisateurs.
1. Connexion et Cloud (synchronisation multi-postes)

🚀 Comment ça marche : À la connexion, le système transfère automatiquement l'URL et la clé Supabase officielles. Chaque modification est immédiatement poussée vers le Cloud. Toutes les 60 secondes, tous les postes connectés récupèrent automatiquement les dernières données.

Identifiants par défaut : utilisateur Admin / mot de passe ktibw (ou admin).

Fenêtres modales : elles ne se ferment jamais en cliquant hors d'elles. Elles sont déplaçables en glissant la barre de titre.

2. Démarrage rapide
  1. Paramètres → Données : importez le fichier Excel des agents (colonnes A à W ; fusion par matricule).
  2. Paramètres → Données : importez les postes occupés (colonne A) pour les combobox.
  3. Paramètres → Chemin d'accès : dossier global ; sous-dossiers matricules créés automatiquement.
  4. Paramètres → Données : 📂 Dossier d'export… → sélectionnez C:\GESTION_DU_PERSONNEL\GESTION.
  5. Agents pour les actions → 🔁 Nouvelle action → type → Continuer.
  6. 💾 Enregistrer ou 💾 Enregistrer & Imprimer (Word) (Téléchargements + [matricule]/Actions).
3. Messages & Fichiers

Nouvel onglet 💬 Messages & Fichiers pour la communication entre utilisateurs :

  • ✉️ Nouveau message : destinataire (tous ou un utilisateur précis), sujet, corps du message.
  • 📎 Envoyer un fichier : tout type de fichier, visible par tous les utilisateurs.
  • Les messages non lus sont marqués en rouge à gauche.
  • Suivi des lecteurs : pour chaque message/fichier, la liste des utilisateurs ayant lu est affichée.
